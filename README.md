# About

Crystal Planner is an event and poll management platform designed specifically for Final Fantasy XIV communities. It provides a simple, centralized way to organize activities, manage registrations, assign party roles and positions, create polls, and keep members informed.

Built for Linkshells, Free Companies, statics, and community groups, Crystal Planner helps coordinate everything from casual events and treasure maps to Extreme, Savage, Chaotic, mount farms, and other group activities. With multilingual support, member management, galleries, Discord integration, and automated community tools, it keeps event organization clear, efficient, and accessible.
